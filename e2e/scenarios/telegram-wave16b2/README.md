# Telegram group call / video chat controls Part 2 (Wave 16B2)

Covers `#463`, `#468`, `#467`, and `#454`:

- **#463 (Recording indicator & admin recording)**: Reads `record_start_date` and `record_video_active` from `GroupCall` and `updateGroupCall`, renders a prominent red `REC` indicator with tooltip ("Recording … since …") in the call header, call dock, and live bar (immediately upon joining an already-recording chat), plays a notice cue when recording starts mid-call, and lets admins with `manage_call` start (audio only / portrait video / landscape video + optional title) and stop server-side recording via `phone.toggleGroupCallRecord` (noting the file arrives in Saved Messages, with no local recording).
- **#468 (Per-person volume, mute for me, & noise suppression)**: Maps Telegram `volume` (`1..=20000`) to `0..=200%` gain and `muted_by_you` per peer (including channels), applies locally via `MediaRequest::Gain`, syncs debounced `phone.editGroupCallParticipant`, keeps local **Mute for me** strictly separate from admin **Mute for everyone** (never sending server mute on admin local mute), and adds a per-call **Noise suppression** toggle in the Telegram call menu defaulting to Settings › Voice.
- **#467 (Camera, screen share, multi-picture grid, & video limit)**: Sends camera (`video_stopped`/`video_paused`), sends screen share over a dedicated presentation transport (`phone.joinGroupCallPresentation` / `phone.leaveGroupCallPresentation`), receives multiple remote camera/presentation feeds with Colibri `ReceiverVideoConstraints` over the WebRTC data channel for pin/fullscreen/pop-out, and enforces `can_start_video` and `unmuted_video_limit` with disabled buttons and a clear reason tooltip.
- **#454 (Channel RTMP live streams)**: Detects `rtmp_stream` on `GroupCall`, shows **Live stream** with viewer count in the live bar, joins as a receive-only viewer (cannot speak) polling `phone.getGroupCallStreamChannels` and fetching `inputGroupCallStream` segments via `upload.getFile` on `stream_dc_id` with quality switching and paused/ended banners, and provides admins with a masked-by-default RTMP server URL & stream key sheet (`phone.getGroupCallStreamRtmpUrl`, never logged) with Copy, Show/Hide, Revoke key, and Start live stream.
