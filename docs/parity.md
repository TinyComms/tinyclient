# What works on each network

Generated by `chatd --capabilities` from the capability ceiling each adapter already reports. The ceiling is what that network can do, not one account's plan. **N** is native, **H** opens the official app, **–** is missing, and **n/a** means the network has no such thing. A – or H cell links to an issue when the generator has one for that gap. Typing indicators and read receipts are not rows: no capability flag says whether this client sends them. Do not edit this file by hand.
