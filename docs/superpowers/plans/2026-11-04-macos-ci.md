# macOS CI build contention

Goal: stop compiling the media engine from nextest child processes and retain useful main caches after test failures. Justin requested the fix directly.

Evidence: run 41915210782 spent 18m14s compiling and 836.886s running tests. Three media tests took 300–305s each. Each calls a process-local Once guard around cargo build; nextest gives every test a separate process. The Darwin test cache was absent; PRs cannot seed a default-branch cache.

Approach: CI builds mediad once, supplies an absolute TINYCLIENT_TEST_MEDIAD path, and separates compilation from test execution. A shared test helper validates that override and otherwise retains local Cargo building, including release mode. Main may save dependencies after test failure; PRs still never save caches. No coverage is removed.

Alternatives: returning to libtest sacrifices nextest isolation and reporting. Caching PR builds duplicates branch-scoped caches and worsens eviction. Neither addresses nested Cargo directly.
