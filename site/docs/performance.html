Size & performance

How big tinyclient is next to the official apps, what it uses while it runs, and how each number was taken.

App size on disk

macOS, measured 2026-10-14 with du -sh on each .app as installed by its vendor’s official macOS installer.
AppSize on disk
Microsoft Teams1.1 GB
Signal625 MB
Slack554 MB
Discord481 MB
Telegram346 MB
The five togetherabout 3.1 GB
tinyclient, all five networks55 MB

Method: install each app from its vendor’s official macOS installer, then run du -sh on the .app bundle. Slack and Telegram ship universal binaries (Apple silicon and Intel in one app); tinyclient’s figure is its Apple silicon build, tinyclient.app from the release zip. We compare size on disk only: we have not measured the official apps’ memory.

Four programs, each only when needed

chatd signed in to Discord and the window, measured on macOS on 2026-10-13. mediad in an end-to-end encrypted call against a local test voice server (crates/mediad/tests/voice.rs).
ProcessRunsMeasuredBudget
chatdAlways, in the background10 MB RSS20 MB idle on Discord, Slack and Teams
tinyclientWhile the window is open64 MB RSS80 MB footprint with a list on screen
mediadDuring a call only< 40 MB RSS40 MB in a voice call; asserted by a test
tinyclient-loginDuring a sign-in onlyn/aExits with the sign-in

The target for the whole product, idle and signed in to four networks, is 150 MB. Voice runs in mediad, which starts when a call connects and exits when it ends, so no audio code is loaded the rest of the time. The sign-in window is its own process and exits when you are in.

Budgets

Every feature has a memory, speed and idle-CPU budget, measured from outside the process. The full list and how each is measured: 07-budgets-and-risk.md. Binary sizes per program are on Architecture.
